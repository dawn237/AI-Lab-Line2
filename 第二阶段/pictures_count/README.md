# 图片统计工具

## 功能介绍
可将指定路径下的图片统计并输出`csv`格式(包括文件
`格式`,`大小`,`路径`)

## 使用指南
该程序相对简陋只支持将被统计文件放入`input`中进行统计  
并在`output`中输出
运行时必须在`src/main.py`中
